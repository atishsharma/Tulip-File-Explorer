## Tulip File Explorer 1.5.0 🌷

A stability, safety and security release. Every issue found in a full code review has been fixed, the app moves to Electron 44, and builds are now produced automatically for Windows, macOS and Linux.

### 🔒 Security
- File names can no longer run shell commands (zip, video details, Windows attributes, rclone all use safe argument lists)
- Web security and sandboxing enabled; the window can't be navigated away or open pop-ups
- External links limited to `https`, `http` and `mailto`
- Local images, video and audio load through a private `tulip-file://` protocol
- Strict Content Security Policy in release builds
- Electron 28 → 44 and all dependencies updated: `npm audit` reports 0 vulnerabilities

### 🛡️ Your files are safer
- **Right-click actions now hit the right file** — previously Delete/Cut/Copy could act on an earlier selection
- **Rename works again** (it was broken in 1.4.3)
- Nothing is ever overwritten: rename, hide, New File, New Folder and Paste add a `(2)` suffix instead
- Pasting a folder into itself is blocked; moving between drives works
- Delete confirmation lists the file names

### ✨ Improvements
- Keyboard shortcuts: `F2` rename, `Alt+Enter` properties, `Enter` open, `Alt+←/→/↑` or `Backspace` to navigate, `F5` refresh
- Back/Forward history survives refresh, delete and rename
- New Folder / New File open straight into rename
- Error messages shown as notifications instead of failing silently
- Cloud drives appear under **This PC → Cloud Locations**; mounts are restored on next launch
- Clear message when rclone isn't installed, with an install link
- Properties: real read-only flag, rename/hide keep working, folder size scan stops when closed
- Breadcrumb handles This PC and network (`\\server\share`) paths
- Full drives now show their capacity instead of a blank bar
- Date sort direction fixed; "Today/Yesterday" use calendar days
- Copy/paste works with other file managers on Linux
- Keyboard and screen-reader improvements for dialogs, cards and toolbar

### ⚡ Performance
- Large folders load much faster (parallel reads)
- Previews read only the first 50 KB of text files — huge logs no longer freeze the app
- Thumbnails are generated in the background and cached; video thumbnails on Windows/macOS (Linux with `ffmpeg`)
- One background drive monitor instead of three polling timers
- Quitting never hangs on a stuck cloud mount

### 📦 Downloads

| System | File | How to install |
|---|---|---|
| **Windows** (x64 / ARM64) | `…-win-x64.zip` / `…-win-arm64.zip` | Unzip and run `Tulip File Explorer.exe` |
| **macOS** (Intel / Apple Silicon) | `…-mac-x64.zip` / `…-mac-arm64.zip` | Unzip, move to Applications. Unsigned: run `xattr -cr "/Applications/Tulip File Explorer.app"` once |
| **Ubuntu / Debian** | `…-linux-amd64.deb` | `sudo apt install ./Tulip-File-Explorer-1.5.0-linux-amd64.deb` |
| **Any Linux** | `…-linux-x86_64.AppImage` | `chmod +x` the file, then run it |
| **Arch / other Linux** | `…-linux-x64.tar.gz` | `tar xzf` the archive, run `tulip-file-explorer` inside |

### Requirements
- **Cloud drives:** [rclone](https://rclone.org/install/) installed and configured; on Windows also [WinFsp](https://winfsp.dev/)
- **Optional:** FFmpeg (`ffprobe`/`ffmpeg`) for video details and Linux video thumbnails

### Known limitations
- Builds are not code-signed: macOS Gatekeeper and Windows SmartScreen may warn on first launch
- PDFs open in your default viewer (no inline preview yet)
