## Tulip File Explorer 1.6.1 🌷 — Glass

A complete visual redesign, plus a proper app icon in every download.

### ✨ New glass design language
- **Frosted glass window** — translucent sidebar, header and panels over a soft ambient backdrop, in both light and dark
- **One-bar header** — back/forward/up, path, search, view switcher, sort, group, icon size and window controls now share a single row; the sidebar runs the full height with the Tulip logo
- **Tulip Rose accent** by default, plus Ocean Blue, Royal Purple, Crimson, Sunset, Forest, Teal and Graphite — each tuned for readable contrast in light and dark
- **Figtree typeface** bundled with the app (works offline)
- **New icons** — consistent line icons everywhere, two-tone folders that follow your accent colour, and document tiles with colour-coded type badges (PDF, DOCX, XLSX, MP4, ZIP…)
- **Folder title and status bar** — each folder shows its name, sort/group state, item count and selected size
- **Preview panel** — larger preview, type badge, clean details list, plus *Open* and *Show in folder*
- **This PC** — colourful library cards, drive cards with usage bars (amber when nearly full) and a Cloud locations section with a *Connect a cloud drive* shortcut
- **Settings** — theme picker with live previews, accent swatches, and new switches for **Glass transparency** (turn off for solid surfaces) and the preview panel
- **Dialogs, menus and notifications** restyled to match; notifications now show success/error icons
- **Breadcrumb** keeps the current folder readable on long paths and has a quick *Type a path* button
- Grid/list view and icon size are remembered between launches

### 🌷 App icon on every build
- All builds now use the Tulip icon: Windows `.exe`, macOS `.app`, Linux `.deb`, AppImage **and the `.tar.gz`**
- The running window and taskbar/dock also show the Tulip icon (it was missing from packaged builds)
- The Linux `tar.gz` includes `install-desktop-entry.sh` to add Tulip to your applications menu with its icon (and `uninstall-desktop-entry.sh` to remove it)
- Icons are now square at every size and regenerated from one source (`npm run icons`)

### 🐞 Fixes
- Transparent PNG, GIF, WebP and SVG thumbnails no longer get a black background
- `Alt+Enter` on a folder in list view opens Properties instead of opening the folder

### 📦 Downloads

| System | File | How to install |
|---|---|---|
| **Windows** (x64 / ARM64) | `…-win-x64.zip` / `…-win-arm64.zip` | Unzip and run `Tulip File Explorer.exe` |
| **macOS** (Intel / Apple Silicon) | `…-mac-x64.zip` / `…-mac-arm64.zip` | Unzip, move to Applications. Unsigned: run `xattr -cr "/Applications/Tulip File Explorer.app"` once |
| **Ubuntu / Debian** | `…-linux-amd64.deb` | `sudo apt install ./Tulip-File-Explorer-1.6.1-linux-amd64.deb` |
| **Any Linux** | `…-linux-x86_64.AppImage` | `chmod +x` the file, then run it |
| **Arch / other Linux** | `…-linux-x64.tar.gz` | `tar xzf` the archive, run `./install-desktop-entry.sh` once, then launch Tulip from your app menu |

### Requirements
- **Cloud drives:** [rclone](https://rclone.org/install/) installed and configured; on Windows also [WinFsp](https://winfsp.dev/)
- **Optional:** FFmpeg (`ffprobe`/`ffmpeg`) for video details and Linux video thumbnails

### Known limitations
- Builds are not code-signed: macOS Gatekeeper and Windows SmartScreen may warn on first launch
- On Linux the glass effect blurs the app's own backdrop; the desktop behind the window is not blurred
